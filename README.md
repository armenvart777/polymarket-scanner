# Polymarket Scanner

Эскиз скрипта для сверки спортивных рынков с результатами матчей. Код собран в одном файле.

В `scanner.py` остались настройки, справочник команд и сигнатуры функций. Получение рынков и результатов, их сопоставление, хранение просмотренных событий и отправка сообщений в Telegram здесь не реализованы.

## Запуск

Утилита не выполняет сканирование. При вызове `python scanner.py` точка входа ничего не делает.
